# v0.9.0-rc1: System testing, adversarial hardening, live mode, and maintenance

The release candidate. The capstone feature set is complete; what remains for
v1.0.0 is hardening and documentation. This release adds the system-level
test suites, the live AWS inventory path, and the maintenance automation.

## Highlights

- Adversarial prompt-injection suite (`make adversarial`): 30 payloads in six
  categories (instruction override, jailbreak, HCL smuggling, exfiltration,
  marker spoofing, bypass) plus 5 benign controls, each with an explicit
  expected outcome. 22 payloads are withheld at the sanitizer; 8 evaders stay
  inside the nonce-fenced data block and are still caught by the independent
  verifier; no benign value is mangled.
- Live mode (`csg run --live`, optional `--role-arn`): a read-only S3 inventory
  (ListBuckets, GetBucketLocation, GetPublicAccessBlock, GetBucketPolicy,
  GetBucketLifecycleConfiguration) mapped into the same normalized resource
  shape as Terraform state, so the analyzers run unchanged. Permission failures
  fail the whole collection instead of returning a partial inventory, and a
  missing configuration is treated as a coverage gap, not as proof of exposure.
- Acceptance test (`make acceptance`): a CLI-level test that starts LocalStack
  (2026.10.0) via testcontainers-go, seeds one public and one locked-down
  bucket, runs `csg run --live`, and asserts that only the public bucket is
  flagged (SEC-S3-PUBLIC-001) and named in the report. Runs in CI as its own
  job; a Docker-free CLI test covers the same path against a fake S3 server.
- Maintenance automation: Dependabot (Go modules and GitHub Actions) and
  Renovate (container images, including the LocalStack pin), plus
  `docs/maintenance.md` with the four maintenance types and their schedule.

## Test evidence

- Unit and integration: all packages pass, including the new live collector
  tests against a fake S3 server (mapping, fail-loud permission errors, and
  the no-configuration-is-not-exposure rule).
- System: `make demo` and `csg run --sample` unchanged, all four report
  formats render; `TestRun_LiveModeStandalone` runs the live pipeline
  end to end against a fake S3 server without Docker.
- Acceptance: developer-run `make acceptance` passed on Docker Desktop on
  October 17, 2026. The LocalStack scenario passed in 10.87 s, the lifecycle
  XML test in 0.00 s, and the package in 11.363 s. This is local user-run
  evidence, not a CI result; see `docs/localstack-acceptance-2026-10-17.md`.
- Performance: the benchmark was re-run for this release; see
  `docs/evaluation.md` for the current numbers.

## Known limits

- Live mode covers S3 only; the remaining services stay on the Terraform and
  CloudTrail paths.
- A bucket with no public-access-block configuration produces no finding by
  itself; closing that gap needs a coverage report, planned for v1.0.0.

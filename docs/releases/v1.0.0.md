# Release v1.0.0

First stable release of CloudSpendGuard. The feature set is unchanged from
`v0.9.0-rc1`; this release closes the capstone by making the repository
self-contained and publishable.

## What changed since v0.9.0-rc1

- No Go runtime changes. The suite was last run in full on the `v0.9.0-rc1` tree, where
  all 100 test functions and 160 subtests passed and core coverage measured 97.2%
  against the 90% gate; those measurements carry forward unchanged.
- Documentation is self-contained: `docs/architecture.md` and
  `docs/survey/simulated-data-note.md` no longer reference files outside the
  repository.
- `scripts/generate_example_survey.py` added so the clearly labelled simulated
  survey example can be regenerated from a public clone.

## Scope reminder

Live mode inventories S3 only, and the S3-prefix CUR input is handled by the
scheduled deployment copying files rather than by the tool. Both boundaries are
documented in `docs/requirements.md`.

## Upgrade

```bash
git fetch --tags
git checkout v1.0.0
make build
```

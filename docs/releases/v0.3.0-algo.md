## CloudSpendGuard v0.3.0-algo: Core algorithms and verified LLM remediation

Unit 5 milestone. CloudSpendGuard now finds 35 kinds of cost and security
problems, spots cost anomalies, ranks everything in one backlog, and can
propose a Terraform fix that an independent verifier checks before you see it.

### Highlights

- **Rule library complete:** 15 cost rules and 20 security rules, each
  security rule mapped to a CIS AWS Foundations Benchmark v3.0.0 control.
- **Cost-anomaly detection:** robust STL decomposition, modified z-score, and
  an Isolation Forest must agree, and the excess must be material. On 400
  synthetic series: precision 0.997, recall 0.910, F1 0.951 (naive 3-sigma
  baseline: F1 0.874). Try `csg anomalies`.
- **Joint prioritizer:** `S = a*savings + b*risk - c*blast`, with log-scaled
  savings, per-component scores on every row, and `--weights a,b,g`.
- **`csg remediate <finding-id>`:** local Ollama by default; OpenAI-compatible
  APIs only with `--allow-remote`, always redacted. Prompt-injection
  guardrails withhold instruction-like tag values. The verifier re-parses the
  patch, rejects scope violations, and re-runs all 35 rules. At most 3
  attempts. Nothing is ever applied automatically.

### Quality

- 79 test functions and 117 subtests, passing with `-race`; CI repeats them on Linux, macOS,
  and Windows.
- Core coverage 97.2% (gate 90%).
- Golden-file tests replay 5 fixtures recorded from a local
  `qwen2.5-coder:1.5b` model.
- Adversarial suite: 12 injection payloads, 9 malicious model answers;
  guardrail false-positive rate 3.3% on 30 benign tag values.

### Fixed during testing

- Unified diff printed added lines before removed lines.
- Floating-point noise on flat billing series produced z-scores in the millions.
- Two RDS rules both claimed 50% of the same bill (savings now compound).
- The verifier approved a patch with an invented `[[CORPORATE_CIDR]]` value
  and a patch that silently dropped `subnet_id`; both are now rejected.

### Upgrade notes

- `Finding` gains `resource.terraform_address` and
  `suggested_remediation.action`; JSON output of `csg analyze` now wraps each
  finding with `rank`, `score`, `savings_component`, `risk_component`, and `blast_component`.
- Sample data changed (392 CUR line items, 22 Terraform resources, 23
  findings). Re-run `make demo`.
